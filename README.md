# exoplanet-data-analysis
Exploratory analysis of exoplanet discovery data using Python, Pandas, Matplotlib, Seaborn and Plotly.

# Exoplanet Data Analysis

## Overview

This project explores a dataset of 1,653 exoplanets using Python.

The analysis examines:

- Planet radius distributions
- Discovery trends over time
- Multi-planet star systems
- Correlations between planetary characteristics
- Interactive 2D and 3D visualisations

## Key Findings

- 1,653 unique exoplanets were identified.
- 1,272 host stars were present.
- TRAPPIST-1 hosted the largest number of planets in the dataset.
- Most planets had radii below 10 Earth radii.
- Discovery counts peaked in 2014.
- Planet radius and mass showed a weak-to-moderate positive correlation.
